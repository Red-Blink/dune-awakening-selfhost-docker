Dune Docker Console, Linux, Windows/WSL2, വെർച്വൽ മെഷീനുകൾ എന്നിവയ്ക്കുള്ള Docker അടിസ്ഥാനത്തിലുള്ള Dune: Awakening ഡെഡിക്കേറ്റഡ് സെർവർ മാനേജറാണ്. വഴികാട്ടിയുള്ള ഇൻസ്റ്റാളേഷനും ബ്രൗസർ പാനലും ഉപയോഗിച്ച് കളിക്കാർ, മാപ്പുകൾ, ബാക്കപ്പുകൾ, അപ്ഡേറ്റുകൾ, സെർവർ പ്രവർത്തനം എന്നിവ കൈകാര്യം ചെയ്യാം.

ഇത് Funcom-മായി ബന്ധമോ അംഗീകാരമോ സാമ്പത്തിക സഹായമോ പിന്തുണയോ ഇല്ലാത്ത അനൗദ്യോഗിക കമ്മ്യൂണിറ്റി പദ്ധതിയാണ്. പദ്ധതി പരീക്ഷണഘട്ടത്തിലാണ്; Funcom സ്വയം ഹോസ്റ്റ് ചെയ്യുന്ന സംവിധാനത്തിന്റെ പ്രവർത്തനം മാറാം.

## നിങ്ങൾക്ക് ചെയ്യാനാകുന്നത്

- **വിന്യസിക്കലും നടത്തിപ്പും:** ബ്രൗസർ സജ്ജീകരണം, അപ്ഡേറ്റുകൾ, സേവന നിയന്ത്രണം, ഷെഡ്യൂൾ ചെയ്ത റീസ്റ്റാർട്ടുകൾ, റീസ്റ്റാർട്ട് ക്യൂ, പരിശോധനയും വീണ്ടെടുക്കലും.
- **തത്സമയ നിരീക്ഷണം:** ഇന്ററാക്ടീവ് മാപ്പുകൾ, കളിക്കാരുടെയും വാഹനങ്ങളുടെയും സ്ഥാനം, വിഭവങ്ങൾ, സെർവർ ആരോഗ്യം, പ്രകടനം, ലോഗുകൾ.
- **Arrakis നിയന്ത്രണം:** മാപ്പുകൾ, Sietch, Deep Desert ക്രമീകരണം, ഓട്ടോ സ്കെയിലിംഗ്, മെമ്മറി, ഗെയിം സജ്ജീകരണം, **പരീക്ഷണാത്മക Regis Tanks**.
- **കളിക്കാരുടെ നടത്തിപ്പ്:** കളിക്കാരും ഗിൽഡുകളും, ഇൻവെന്ററി, പുരോഗതി, ബേസുകൾ, സംഭരണം, വാഹനങ്ങൾ, Landsraad, പ്രതിഫലങ്ങൾ, Care Packages.
- **സമ്പദ്‌വ്യവസ്ഥ:** Exchange ലിസ്റ്റിംഗുകൾ കാണുകയും ഉൾപ്പെടുത്തിയ Market Bot വഴി വ്യാപാരം ഓട്ടോമേറ്റ് ചെയ്യുകയും ചെയ്യാം.
- **സെർവർ സംരക്ഷണം:** ഡാറ്റാബേസ്, എൻക്രിപ്റ്റ് ചെയ്ത സിസ്റ്റം ബാക്കപ്പുകൾ, പുനഃസ്ഥാപനം, മൈഗ്രേഷൻ, പ്രവേശന റോളുകൾ, പരിമിത അനുമതിയുള്ള API കീകൾ, എൻക്രിപ്റ്റ് ചെയ്ത API.
- **നിർമാണവും പങ്കിടലും:** 3D ബേസ് രൂപകൽപ്പന, ബ്ലൂപ്രിന്റ് ഇംപോർട്ടും പങ്കിടലും, പൊതു സെർവർ പ്രൊഫൈലും ലാറ്റൻസി പരിശോധനയും.
- **ഇഷ്ടാനുസരണം:** കമ്മ്യൂണിറ്റി ആഡോണുകൾ, Discord, വിവിധ ഭാഷകൾ, കമ്മ്യൂണിറ്റി വിവർത്തന തിരുത്തലുകൾ.

നിയന്ത്രണം ഏറ്റെടുത്ത് നിങ്ങളുടെ കമാൻഡ് സെന്റർ അടുത്തറിയൂ! ഇൻസ്റ്റാൾ ചെയ്യാതെ സാമ്പിൾ ഡാറ്റ ഉപയോഗിച്ച് [കൺസോൾ പരീക്ഷിക്കൂ](https://try.dunedocker.app/).

## ആവശ്യകതകൾ

Linux വിദഗ്ധനാകേണ്ടതില്ല. ഇൻസ്റ്റാളർ അടിസ്ഥാന കാര്യങ്ങൾ പരിശോധിച്ച് പിന്തുണയുള്ള Linux-ൽ Docker തയ്യാറാക്കും.

| ഘടകം | നിർദേശം |
|---|---|
| സെർവർ | പുതുതായി ഇൻസ്റ്റാൾ ചെയ്ത 64-bit Ubuntu ഏറ്റവും എളുപ്പം. മറ്റ് Linux, Windows/WSL2-യിലെ Docker Desktop, വെർച്വൽ മെഷീനുകൾ എന്നിവയും പിന്തുണയ്ക്കുന്നു. |
| Docker | പിന്തുണയുള്ള Linux-ൽ ഇല്ലെങ്കിൽ ഇൻസ്റ്റാളർ തയ്യാറാക്കും. |
| CPU | AVX/AVX2 പിന്തുണ |
| മെമ്മറി | ആദ്യം 20 GB RAM; അധിക സ്ഥിരം മാപ്പുകൾക്ക് 30–40 GB അല്ലെങ്കിൽ കൂടുതൽ |

ഇന്റർനെറ്റ് ഹോസ്റ്റിംഗിന് ഈ പോർട്ടുകൾ ഫോർവേഡ് ചെയ്യുക:

| പോർട്ട് | പ്രോട്ടോക്കോൾ | ഉപയോഗം |
|---|---|---|
| `8088` | TCP | വെബ് അഡ്മിൻ, വിശ്വസ്ത അഡ്മിനുകൾ മാത്രം |
| `31982` | TCP | RabbitMQ ഗെയിം മെസേജിംഗ് എൻഡ്പോയിന്റ് |
| `31983` | TCP | RabbitMQ ഗെയിം HTTP എൻഡ്പോയിന്റ് |
| `7777-7810` | UDP | ഗെയിം ട്രാഫിക് |
| `32000-32015` | UDP | ഐച്ഛിക നേരിട്ടുള്ള ലാറ്റൻസി പരിശോധന; അടച്ചാലും relay ലഭ്യമാണ് |
| `8797` | TCP | ഐച്ഛിക HTTPS API; [എൻക്രിപ്റ്റ് ചെയ്ത API പ്രവേശനം](../console/encrypted-api.md) |

ഡാറ്റാബേസ്, ആന്തരിക അഡ്മിൻ പോർട്ടുകൾ സ്വകാര്യമായി സൂക്ഷിക്കുക. വിശ്വാസമില്ലാത്തവർക്ക് വെബ് പാനൽ തുറക്കരുത്.

## ഇൻസ്റ്റാളേഷൻ

`root` ആയി ലോഗിൻ ചെയ്യാതെ `sudo` ഉള്ള സാധാരണ അക്കൗണ്ട് ഉപയോഗിക്കുക. ആവശ്യത്തിനു മാത്രം അഡ്മിൻ അനുമതി ചോദിക്കും. പുതിയ Linux സെർവറിൽ പ്രവർത്തിപ്പിക്കുക:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | sh
```

ഏറ്റവും പുതിയ റിലീസ് ഡൗൺലോഡ് ചെയ്ത് വെബ് പാനൽ തുടങ്ങുകയും വിലാസം കാണിക്കുകയും ചെയ്യും. ബ്രൗസറിൽ പൂർത്തിയാക്കുക. ഡിഫോൾട്ട് പാത `~/dune-awakening-selfhost-docker` ആണ്. മറ്റൊരു ഡിസ്കിന് പൂർണ പാത നൽകുക:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | DUNE_INSTALL_DIR=/mnt/dune/dune-awakening-selfhost-docker sh
```

Windows-ൽ പിന്തുണയുള്ള Linux VM അല്ലെങ്കിൽ Ubuntu WSL2 ടെർമിനൽ ഉപയോഗിക്കുക; PowerShell, Command Prompt, Docker Desktop-ന്റെ ആന്തരിക shell എന്നിവയല്ല. ഫയലുകൾ തുറക്കുന്നതിനു മുമ്പ് എഴുത്താനുമതിയും സ്ഥലവും പരിശോധിക്കും; ഡൗൺലോഡ് പരാജയം ഇൻസ്റ്റാളേഷൻ ഭാഗികമായി മാറ്റില്ല.

Alpine Linux വിതരണത്തിന്റെ Docker/Docker Compose പാക്കേജുകളും OpenRC-യും ഉപയോഗിക്കുന്നു. community repository ഇല്ലെങ്കിൽ ക്രമീകരണം മാറ്റുന്നതിനു മുമ്പ് സമ്മതം ചോദിക്കും.

## പൊതു സെർവർ ഡയറക്ടറി

[DuneDocker.app](https://dunedocker.app/) കമ്മ്യൂണിറ്റികളെ പരിചയപ്പെടുത്തുകയും കളിക്കാർക്ക് സെർവർ കണ്ടെത്താൻ സഹായിക്കുകയും ചെയ്യുന്നു. തത്സമയ പേജിൽ നില, കളിക്കാരുടെ എണ്ണം, പ്രദേശം, Sietch, വ്യക്തിഗത ലാറ്റൻസി, ഐച്ഛിക Discord ലിങ്ക് എന്നിവ കാണാം.

Console ക്രമീകരണത്തിൽ ലിസ്റ്റിംഗ് ക്ലെയിം ചെയ്ത് ഉടമസ്ഥത സ്ഥിരീകരിക്കുക, പ്രൊഫൈലും Discord ക്ഷണവും കൈകാര്യം ചെയ്ത് സെർവർ പ്രചരിപ്പിക്കുക. പൊതു ലിസ്റ്റിംഗ് എപ്പോൾ വേണമെങ്കിലും മാറ്റാം.

നേരിട്ടുള്ള അളവ് UDP `32000-32015` ഉപയോഗിക്കുന്നു; ഹോസ്റ്റ് firewall, internet–DMZ firewall, NAT എന്നിവയിൽ അനുവദിക്കുക. അടച്ചാലും സെർവർ അനുയോജ്യമാണ്; Dune Docker relay സ്വയം ഉപയോഗിക്കും.

ലോക്കൽ അല്ലെങ്കിൽ LAN മാത്രം സെർവറുകൾ ലിസ്റ്റ് ചെയ്യില്ല. ഡിഫോൾട്ടായി പേരുകൾ, വിലാസങ്ങൾ, കളിക്കാർ, ക്രമീകരണങ്ങൾ ഇല്ലാത്ത അജ്ഞാത സെർവർ എണ്ണം മാത്രം നൽകും. ഈ കണക്കെടുപ്പും ക്രമീകരണത്തിൽ പ്രത്യേകം നിർത്താം.

## ബേസ് ഡിസൈനർ

[Dune Docker Base Builder](https://blueprints.dunedocker.app/) ബ്രൗസറിൽ 3D ബേസുകൾ ആസൂത്രണം ചെയ്യാനും പങ്കിടാനും സഹായിക്കുന്നു. ഗെയിമിൽ സമയവും സാധനങ്ങളും ചെലവിടുന്നതിനു മുമ്പ് തിരയാവുന്ന കാറ്റലോഗ്, സ്ഥാപിക്കൽ, snapping, തിരിക്കൽ, collision, പ്രദേശ പരിധി എന്നിവ ഉപയോഗിച്ച് പരീക്ഷിക്കുക.

കാഴ്ചയും പകലും രാത്രിയും മാറ്റുക, നടന്ന് കാണുക, ചിത്രം എടുക്കുക, layout ഇറക്കുമതിയും design കയറ്റുമതിയും ചെയ്യുക. ലോഗിൻ ചെയ്തവർക്ക് സംരക്ഷണം, public/unlisted/private ദൃശ്യത, preview പ്രസിദ്ധീകരണം, കമ്മ്യൂണിറ്റി രൂപകൽപ്പനകൾ കാണൽ, പകർത്തൽ എന്നിവ സാധ്യമാണ്. Console footer-ലും ലിങ്കുണ്ട്.

## കമ്മ്യൂണിറ്റി ആഡോണുകൾ

ഐച്ഛിക ഉപകരണങ്ങൾ വെബ് പാനലിൽ ഇൻസ്റ്റാൾ ചെയ്ത് കൈകാര്യം ചെയ്യാം. അനുമതികൾ മുൻകൂട്ടി അറിയിക്കും; അപ്ഡേറ്റുകൾ ക്രമീകരണം നിലനിർത്തുകയും പുതിയ അനുമതിക്ക് സമ്മതം തേടുകയും ചെയ്യും. വികസിപ്പിക്കുന്നവർക്ക് [ഔദ്യോഗിക ആഡോൺ മാതൃക](https://github.com/Red-Blink/dune-docker-addon-template) ഉപയോഗിക്കാം.

വികസിപ്പിക്കുന്നവർക്കും സെർവർ ഉടമകൾക്കും കളിക്കാർക്കും സ്വാഗതം. ആവർത്തനം ഒഴിവാക്കാൻ [issues](https://github.com/Red-Blink/dune-awakening-selfhost-docker/issues), [pull requests](https://github.com/Red-Blink/dune-awakening-selfhost-docker/pulls) എന്നിവ ആദ്യം കാണുക.

- **പിഴവ് അറിയിക്കുക:** പതിപ്പ്, ആവർത്തിക്കാനുള്ള ഘട്ടങ്ങൾ, പ്രതീക്ഷിച്ച ഫലം; ലോഗിലും ചിത്രത്തിലും പാസ്വേഡും സ്വകാര്യ വിവരവും നീക്കുക.

- **Pull Request നൽകുക:** പരിധി ചുരുക്കുക, ബന്ധപ്പെട്ട issues ചേർക്കുക, മാറ്റവും പരിശോധനയും വിവരിക്കുക.
- **കോഡിനു പുറത്തും സഹായിക്കുക:** രേഖകൾ, പരിശോധന, ആഡോണുകൾ, Console-ലെ വിവർത്തന തിരുത്തൽ നിർദേശങ്ങൾ.
