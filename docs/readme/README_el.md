# Dune: Awakening Docker - Self-Hosted Server Console

Το Dune Docker Console διαχειρίζεται αποκλειστικούς διακομιστές Dune: Awakening μέσω Docker σε Linux, Windows/WSL2 και εικονικές μηχανές. Προσφέρει καθοδηγούμενη εγκατάσταση και πίνακα στον περιηγητή για παίκτες, χάρτες, αντίγραφα ασφαλείας, ενημερώσεις και λειτουργία του διακομιστή.

Είναι ανεπίσημο κοινοτικό έργο, χωρίς σύνδεση, έγκριση, χορηγία ή υποστήριξη από τη Funcom. Είναι πειραματικό· η συμπεριφορά της αυτοφιλοξενίας Funcom μπορεί να αλλάξει.

## Τι Μπορείτε να Κάνετε

- **Εγκατάσταση και Λειτουργία:** Ρύθμιση στον περιηγητή, ενημερώσεις, έλεγχος υπηρεσιών, προγραμματισμός και ουρά επανεκκινήσεων, διάγνωση και ανάκτηση.
- **Ζωντανή Παρακολούθηση:** Διαδραστικοί χάρτες, παίκτες και οχήματα, πόροι, κατάσταση διακομιστή, επιδόσεις και αρχεία καταγραφής.
- **Έλεγχος του Arrakis:** Χάρτες, Sietch, διατάξεις Deep Desert, αυτόματη κλιμάκωση, μνήμη, ρυθμίσεις παιχνιδιού και **πειραματικά Regis Tanks**.
- **Διαχείριση Παικτών:** Εργαλεία παικτών και συντεχνιών, αποθέματα, πρόοδος, βάσεις, αποθήκες, οχήματα, Landsraad, ανταμοιβές και Care Packages.
- **Διαχείριση Οικονομίας:** Προβολή προσφορών Exchange και αυτοματοποιημένο εμπόριο με το ενσωματωμένο Market Bot.
- **Προστασία Διακομιστή:** Αντίγραφα βάσης και κρυπτογραφημένα αντίγραφα συστήματος, επαναφορά, μετεγκατάσταση, ρόλοι πρόσβασης, κλειδιά API περιορισμένων δικαιωμάτων και κρυπτογραφημένο API.
- **Κατασκευή και Κοινοποίηση:** Σχεδίαση βάσεων 3D, εισαγωγή και κοινοποίηση σχεδίων, δημόσιο προφίλ και μέτρηση καθυστέρησης.
- **Προσαρμογή:** Πρόσθετα κοινότητας, Discord, πολλές γλώσσες και κοινοτικές διορθώσεις μεταφράσεων.

Πάρτε τον έλεγχο και εξερευνήστε το κέντρο διοίκησής σας! [Δοκιμάστε την κονσόλα](https://try.dunedocker.app/) με ενδεικτικά δεδομένα, χωρίς εγκατάσταση.

## Απαιτήσεις

Δεν απαιτείται ειδίκευση στο Linux. Το πρόγραμμα εγκατάστασης ελέγχει τις προϋποθέσεις και προετοιμάζει το Docker σε υποστηριζόμενα Linux.

| Στοιχείο | Σύσταση |
|---|---|
| Διακομιστής | Νέα εγκατάσταση Ubuntu 64 bit για ευκολία. Υποστηρίζονται άλλα Linux, Docker Desktop σε Windows/WSL2 και εικονικές μηχανές. |
| Docker | Προετοιμάζεται αυτόματα σε υποστηριζόμενο Linux αν λείπει. |
| CPU | AVX/AVX2 |
| Μνήμη | Αρχικά 20 GB RAM· 30–40 GB ή περισσότερα για πρόσθετους μόνιμους χάρτες |
| Αποθήκευση | 200 GB ή περισσότερα |
| Token Funcom | Ασφαλής εισαγωγή στη ρύθμιση του περιηγητή |

Για δημόσια φιλοξενία προωθήστε τις θύρες:

| Θύρα | Πρωτόκολλο | Χρήση |
|---|---|---|
| `8088` | TCP | Διαχείριση web μόνο για έμπιστους διαχειριστές |
| `31982` | TCP | Μηνύματα παιχνιδιού RabbitMQ |
| `31983` | TCP | HTTP παιχνιδιού RabbitMQ |
| `7777-7810` | UDP | Κίνηση παιχνιδιού |
| `32000-32015` | UDP | Προαιρετική άμεση μέτρηση καθυστέρησης· διαθέσιμος αναμεταδότης αν κλείσουν |
| `8797` | TCP | Προαιρετικό HTTPS API· [Κρυπτογραφημένη Πρόσβαση API](../console/encrypted-api.md) |

Κρατήστε ιδιωτικές τις θύρες βάσης και εσωτερικής διαχείρισης. Μην εκθέτετε το web UI σε μη έμπιστους χρήστες.

## Εγκατάσταση

Χρησιμοποιήστε κανονικό λογαριασμό με `sudo`, όχι σύνδεση ως `root`. Δικαιώματα διαχειριστή ζητούνται μόνο όταν χρειάζονται. Σε νέο Linux εκτελέστε:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | sh
```

Κατεβάζει την τελευταία έκδοση, εκκινεί τον πίνακα και εμφανίζει διεύθυνση. Ολοκληρώστε στον περιηγητή. Προεπιλογή: `~/dune-awakening-selfhost-docker`. Για άλλον δίσκο ορίστε πλήρη διαδρομή:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | DUNE_INSTALL_DIR=/mnt/dune/dune-awakening-selfhost-docker sh
```

Σε Windows χρησιμοποιήστε τερματικό υποστηριζόμενης Linux VM ή Ubuntu WSL2, όχι PowerShell, Command Prompt ή εσωτερικό κέλυφος Docker Desktop. Πριν την αποσυμπίεση ελέγχονται εγγραφή και χώρος· αποτυχημένη λήψη δεν αντικαθιστά μερικώς την εγκατάσταση.

Το Alpine Linux χρησιμοποιεί πακέτα Docker/Docker Compose της διανομής και OpenRC. Αν λείπει το αποθετήριο community, ζητείται συγκατάθεση πριν αλλάξει η ρύθμιση.

## Δημόσιος Κατάλογος Διακομιστών

Το [DuneDocker.app](https://dunedocker.app/) παρουσιάζει κοινότητες και βοηθά στην εύρεση διακομιστών. Οι ζωντανές σελίδες δείχνουν κατάσταση, παίκτες, περιοχή, Sietch, προσωπική καθυστέρηση και προαιρετικό Discord.

Από τις Ρυθμίσεις Console διεκδικήστε την εγγραφή για επιβεβαίωση ιδιοκτησίας, προφίλ, πρόσκληση Discord και προβολή. Η δημοσίευση αλλάζει οποτεδήποτε.

Η άμεση μέτρηση χρησιμοποιεί UDP `32000-32015`: επιτρέψτε το στο host, στο τείχος internet–DMZ και στο NAT. Διαφορετικά χρησιμοποιείται αυτόματα ο αναμεταδότης Dune Docker χωρίς απώλεια συμβατότητας.

Τοπικοί ή αποκλειστικά LAN διακομιστές δεν καταχωρίζονται. Προεπιλεγμένα συνεισφέρουν μόνο σε ανώνυμο πλήθος, χωρίς ονόματα, διευθύνσεις, παίκτες ή ρυθμίσεις. Απενεργοποιείται χωριστά στις Ρυθμίσεις.

## Σχεδιαστής Βάσεων

Το [Dune Docker Base Builder](https://blueprints.dunedocker.app/) προσφέρει σχεδίαση και κοινοποίηση βάσεων 3D στον περιηγητή. Δοκιμάστε πριν ξοδέψετε χρόνο και υλικά στο παιχνίδι: κατάλογος με αναζήτηση, τοποθέτηση, προσκόλληση, περιστροφή, συγκρούσεις και κάλυψη εδάφους.

Αλλάξτε γωνίες και ημέρα/νύχτα, περπατήστε, φωτογραφίστε, εισαγάγετε διατάξεις και εξαγάγετε σχέδια. Με σύνδεση μπορείτε να αποθηκεύετε, να επιλέγετε δημόσια/μη καταχωρισμένη/ιδιωτική ορατότητα, να δημοσιεύετε προεπισκοπήσεις, να εξερευνάτε και να αντιγράφετε σχέδια κοινότητας. Σύνδεσμος υπάρχει και στο υποσέλιδο Console.
