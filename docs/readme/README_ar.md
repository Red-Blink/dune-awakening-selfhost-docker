Dune Docker Console أداة لإدارة خوادم Dune: Awakening المخصصة باستخدام Docker، وتدعم Linux وWindows/WSL2 والأجهزة الافتراضية. توفر تثبيتًا موجهًا ولوحة إدارة في المتصفح لإدارة اللاعبين والخرائط والنسخ الاحتياطية والتحديثات وتشغيل الخادم دون الاعتماد المستمر على الطرفية.

هذا مشروع مجتمعي غير رسمي، ولا يتبع Funcom ولا يحظى باعتمادها أو رعايتها أو دعمها.

المشروع تجريبي، وقد تتغير طريقة عمل الاستضافة الذاتية لدى Funcom بمرور الوقت.

## ما الذي يمكنك فعله

- **التثبيت والتشغيل:** إعداد موجه في المتصفح، وتحديثات، وتحكم بالخدمات، وإعادة تشغيل مجدولة، وقوائم انتظار لإعادة التشغيل، وتشخيص واستعادة.
- **المتابعة المباشرة:** خرائط عالم تفاعلية، وتتبع اللاعبين والمركبات، ومواقع الموارد، وحالة الخادم، والأداء والسجلات.
- **إدارة أراكس:** إعداد الخرائط وSietches وتوزيعات Deep Desert والتوسع التلقائي والذاكرة وإعدادات اللعب، مع دعم **Regis Tanks التجريبي**.
- **إدارة اللاعبين:** أدوات للاعبين والنقابات، والمخزون، والتقدم، والقواعد، والتخزين، والمركبات، وLandsraad، والمكافآت وCare Packages.
- **إدارة الاقتصاد:** تصفح عروض Exchange وأتمتة التداول باستخدام Market Bot المدمج.
- **حماية الخادم:** نسخ احتياطية لقاعدة البيانات وللنظام بتشفير، وأدوات للاستعادة والنقل، وأدوار وصول، ومفاتيح API بصلاحيات محددة، ووصول مشفر إلى API.
- **البناء والمشاركة:** تصميم قواعد ثلاثية الأبعاد، واستيراد المخططات ومشاركتها، وعرض خادمك بملف عام وفحوص زمن الاستجابة.
- **التخصيص:** إضافات المجتمع، والتكامل مع Discord، ولغات متعددة للوحة Console، وتصحيحات ترجمة من المجتمع.

اطلع على [معرض لقطات الشاشة](../screenshots.md) لإلقاء نظرة أقرب.

## المتطلبات

لا تحتاج إلى أن تكون خبيرًا في Linux. يفحص المثبت المتطلبات الأساسية ويجهز Docker على أنظمة Linux المدعومة.

| المتطلب | التوصية |
|---|---|
| الخادم | يوصى بخادم Ubuntu جديد بمعمارية 64 بت، فهو الخيار الأسهل. تدعم الأداة أيضًا توزيعات Linux الأخرى وDocker Desktop على Windows/WSL2 والأجهزة الافتراضية. |
| Docker | يجهز المثبت Docker على أنظمة Linux المدعومة إذا لم يكن متاحًا بالفعل. |
| المعالج | دعم AVX/AVX2 |
| الذاكرة | ابدأ بسعة 20 GB RAM؛ استخدم 30–40 GB أو أكثر للخرائط الإضافية التي تعمل باستمرار |
| التخزين | 200 GB أو أكثر |
| رمز Funcom | يُدخل بأمان أثناء الإعداد في المتصفح |

على الأجهزة التي تستخدم SELinux، مثل Fedora وBazzite، تتضمن الإعدادات وسمًا مشتركًا لتركيبات مجلدات المشروع، وتلغي العزل بالوسوم للوحة Console وحدها لأنها تحتاج إلى الوصول إلى مقبس Docker على المضيف. يظل SELinux مفعّلًا على المضيف، ولا تتغير وسوم مقبس Docker أو صلاحياته. بعد ترقية تثبيت موجود، شغّل `dune console reload` لتطبيق هذه الإعدادات على Console. يجب تثبيت Docker مسبقًا إذا كان مثبت Docker التلقائي لا يدعم توزيعتك.

<details>
<summary>إرشادات الذاكرة والمعالج</summary>

تحدد RAM عدد خوادم خرائط Dune التي يمكن تشغيلها بأريحية. إذا لم تكن متأكدًا، ابدأ بالتوزيع الأساسي وأضف ذاكرة للخرائط الإضافية التي تعمل باستمرار أو لنشاط اللاعبين الأكبر.

عادةً يحتفظ خادم Survival الرسمي بنحو 10–12 GB من الذاكرة المقيمة حتى دون لاعبين متصلين؛ وقراءة واحدة في حالة الخمول لا تثبت بحد ذاتها وجود تسرب للذاكرة. في `docker stats` يُقاس استهلاك المعالج بوحدات الأنوية: تعني `100%` استخدام معالج منطقي واحد بالكامل.

| توزيع الخادم | RAM الموصى بها |
|---|---:|
| خادم أساسي للبدء | 20 GB |
| العالم الرئيسي مع خرائط قصصية/اجتماعية إضافية | 30 GB |
| العالم الرئيسي وخرائط إضافية وDeep Desert | 40 GB |
| خرائط كثيرة تعمل باستمرار أو نشاط لاعبين أكبر | 60 GB+ |

</details>

للاستضافة العامة على الإنترنت، وجّه هذه المنافذ:

| المنفذ | البروتوكول | الغرض |
|---|---|---|
| `8088` | TCP | لوحة إدارة الويب؛ اسمح للمسؤولين الموثوقين فقط |
| `31982` | TCP | نقطة اتصال رسائل اللعبة عبر RabbitMQ |
| `31983` | TCP | نقطة اتصال HTTP للعبة عبر RabbitMQ |
| `7777-7810` | UDP | حركة بيانات اللعبة |
| `32000-32015` | UDP | فحوص مباشرة اختيارية لزمن الاستجابة في الدليل العام؛ يبقى الوسيط متاحًا عند إغلاقها |
| `8797` | TCP | وصول مشفر اختياري إلى API عبر HTTPS؛ انظر [الوصول المشفر إلى API](../console/encrypted-api.md) |

أبقِ منافذ قاعدة البيانات والإدارة الداخلية خاصة. لا تعرض واجهة الويب لمستخدمين غير موثوقين.

## التثبيت

شغّل المثبت من حساب مستخدم عادي لديه صلاحية `sudo`، دون تسجيل الدخول بحساب `root`. يطلب المثبت صلاحيات المسؤول عند الحاجة فقط.

انسخ هذا الأمر والصقه على خادم Linux جديد:

<div dir="ltr">

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | sh
```

</div>

ينزل المثبت أحدث إصدار ويشغّل واجهة الويب ويخبرك بالعنوان المطلوب فتحه. أكمل بقية الإعداد في المتصفح.

مسار التثبيت الافتراضي هو `~/dune-awakening-selfhost-docker`. لاستخدام قرص Linux آخر، حدد مسار الوجهة الكامل صراحةً:

<div dir="ltr">

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | DUNE_INSTALL_DIR=/mnt/dune/dune-awakening-selfhost-docker sh
```

</div>

على Windows، نفذ الأمر في طرفية جهاز Linux افتراضي مدعوم أو Ubuntu WSL2، وليس في PowerShell أو موجه أوامر Windows أو الطرفية الداخلية لـDocker Desktop. يفحص المثبت قابلية الكتابة والمساحة قبل فك الملفات، ولا تترك التنزيلات الفاشلة تثبيتًا استُبدلت بعض ملفاته فقط.

على Alpine Linux، يستخدم المثبت حزم Docker وDocker Compose الخاصة بالتوزيعة ويشغّل Docker عبر OpenRC. إذا لم يكن مستودع community متاحًا، يطلب المثبت الموافقة قبل تعديل إعدادات المستودعات.

## دليل الخوادم العام

يساعد [DuneDocker.app](https://dunedocker.app/) أصحاب الخوادم العامة على عرض مجتمعاتهم، ويساعد اللاعبين على العثور على الخادم المناسب. توفر كل قائمة صفحة مباشرة تعرض الحالة وعدد اللاعبين والمنطقة وSietches وزمن الاستجابة الخاص بالزائر ورابط Discord اختياريًا.

يمكن للمالك المطالبة بقائمة خادمه مباشرة من صفحة الإعدادات في Console لإثبات الملكية وإدارة الملف العام ودعوة Discord والترويج للخادم عبر الدليل. يمكن تفعيل الظهور العام أو تعطيله في أي وقت.

تستخدم قياسات زمن الاستجابة UDP `32000-32015` لأسرع قياس مباشر. اسمح بهذا النطاق في جدار حماية المضيف، وكذلك في أي جدار حماية بين الإنترنت وDMZ أو تحويل NAT. تبقى الخوادم التي لا تفتح هذا النطاق متوافقة، وتستخدم وسيط Dune Docker تلقائيًا.

لا تُدرج الخوادم المحلية أو المخصصة للشبكة المحلية فقط. وللشفافية، تسهم التثبيتات افتراضيًا في إحصاء مجهول لعدد الخوادم فقط، دون أسماء أو عناوين أو لاعبين أو إعدادات. يمكن تعطيل هذا الخيار بشكل مستقل في الإعدادات.

## مصمم القواعد

[Dune Docker Base Builder](https://blueprints.dunedocker.app/) أداة متصفح لتخطيط قواعد Dune: Awakening ومشاركتها بتصميم ثلاثي الأبعاد. جرّب توزيعاتك قبل إنفاق الوقت والمواد داخل اللعبة، باستخدام فهرس قابل للبحث للهياكل والعناصر القابلة للوضع، وأدوات للوضع والالتصاق والتدوير والتصادم وتغطية منطقة المطالبة.

عاين التصميم من زوايا مختلفة، وبدّل بين النهار والليل، وتجول داخل التصميم النهائي والتقط الصور. يمكنك استيراد توزيعات موجودة للتخطيط وتصدير التصاميم المكتملة لاستخدامها لاحقًا.

يمكن لأعضاء المجتمع المسجلين حفظ المشاريع واختيار ظهور عام أو غير مدرج أو خاص، ونشر المعاينات واستكشاف تصاميم المجتمع وإنشاء نسخة من مخطط منشور كنقطة بداية. يوجد أيضًا رابط مباشر للمصمم في تذييل Console.

## إضافات المجتمع

توفر إضافات المجتمع أدوات اختيارية يمكن تثبيتها وإدارتها من واجهة الويب. تعلن الإضافات صلاحياتها قبل التثبيت، وتحافظ التحديثات على إعداداتها وتتطلب الموافقة على أي صلاحيات جديدة.

يمكن للمطورين البدء من [القالب الرسمي للإضافات](https://github.com/Red-Blink/dune-docker-addon-template).

## المساهمة

يرحب Dune Docker بمساهمات المطورين وأصحاب الخوادم واللاعبين. راجع [البلاغات](https://github.com/Red-Blink/dune-awakening-selfhost-docker/issues) و[طلبات الدمج](https://github.com/Red-Blink/dune-awakening-selfhost-docker/pulls) الحالية قبل البدء لتجنب تكرار العمل.

- **الإبلاغ عن الأخطاء:** اذكر إصدار المشروع وخطوات إعادة المشكلة والنتيجة المتوقعة. أرفق السجلات أو الصور ذات الصلة بعد إزالة كلمات المرور والبيانات الشخصية.
- **اقتراح التحسينات:** وضح المشكلة التي تحلها فكرتك وفائدتها للمجتمع. ناقش التغييرات الكبيرة في بلاغ قبل تنفيذها.
- **إرسال طلبات الدمج:** اجعل التغييرات محددة، واربط البلاغات ذات الصلة، واشرح ما تغير وكيف اختبرته.
- **المساعدة خارج البرمجة:** حسّن التوثيق أو اختبر التغييرات أو أنشئ إضافات، أو اقترح تصحيحات ترجمة مباشرة من Console.

للأسئلة أو مناقشة الأفكار، انضم إلى [مجتمع Discord](https://discord.gg/duneawakeningdocker).
