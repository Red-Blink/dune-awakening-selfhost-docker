Dune Docker Console — менеджер виділених серверів Dune: Awakening на Docker для Linux, Windows/WSL2 і віртуальних машин. Покрокове встановлення та вебпанель допомагають керувати гравцями, мапами, резервними копіями, оновленнями й роботою сервера.

Це неофіційний проєкт спільноти без зв’язку, схвалення, спонсорства чи підтримки Funcom. Проєкт експериментальний; поведінка самостійного хостингу Funcom може змінюватися.

## Що Ви Можете Робити

- **Розгортати й Обслуговувати:** Налаштування у браузері, оновлення, керування службами, розклад і черга перезапусків, діагностика та відновлення.
- **Спостерігати Наживо:** Інтерактивні мапи, відстеження гравців і транспорту, ресурси, стан сервера, продуктивність і журнали.
- **Налаштовувати Арракіс:** Мапи, сітчі, схеми Deep Desert, автоматичне масштабування, пам’ять, параметри гри й **експериментальні Regis Tanks**.
- **Керувати Гравцями:** Інструменти гравців і гільдій, інвентар, прогрес, бази, сховища, транспорт, Landsraad, нагороди та Care Packages.
- **Керувати Економікою:** Перегляд оголошень Exchange та автоматична торгівля вбудованим Market Bot.
- **Захищати Сервер:** Копії бази даних і зашифровані копії системи, відновлення, перенесення, ролі доступу, API-ключі з обмеженими правами та зашифрований API.
- **Будувати й Ділитися:** Проєктування баз у 3D, імпорт і обмін кресленнями, публічний профіль сервера та перевірки затримки.
- **Налаштовувати Під Себе:** Доповнення спільноти, Discord, мови Console та виправлення перекладів від спільноти.

Перегляньте [Галерею Знімків](../screenshots.md).

## Вимоги

Знання експерта Linux не потрібні: інсталятор перевіряє основні умови й готує Docker у підтримуваних системах Linux.

| Компонент | Рекомендація |
|---|---|
| Сервер | Найпростіше — свіжа 64-бітна Ubuntu. Підтримуються інші Linux, Docker Desktop на Windows/WSL2 і віртуальні машини. |
| Docker | Інсталятор готує його в підтримуваних Linux, якщо ще немає. |
| CPU | AVX/AVX2 |
| Пам’ять | Починайте з 20 GB RAM; 30–40 GB і більше для додаткових постійних мап |
| Диск | 200 GB і більше |
| Токен Funcom | Безпечне введення під час налаштування у браузері |

На SELinux-хостах Fedora, Bazzite тощо використовується спільна мітка монтувань проєкту. Обмеження мітками вимикається лише для Console, якій потрібен Docker-сокет хоста; SELinux хоста, мітки та права сокета не змінюються. Після оновлення виконайте `dune console reload`. Якщо автоматичний інсталятор Docker не підтримує дистрибутив, установіть Docker заздалегідь.

<details>
<summary>Пам’ять і Процесор</summary>

RAM визначає кількість мап, які працюватимуть комфортно. Починайте з базової схеми та додавайте пам’ять для постійних мап і активності гравців. Офіційний Survival часто тримає близько 10–12 GB резидентної пам’яті навіть без гравців; один замір у простої не доводить витоку. У `docker stats` значення `100%` означає повне використання одного логічного CPU.

| Схема | Рекомендована RAM |
|---|---:|
| Базовий сервер | 20 GB |
| Основний світ і сюжетні/соціальні мапи | 30 GB |
| Основний світ, додаткові мапи та Deep Desert | 40 GB |
| Багато постійних мап або висока активність | 60 GB+ |

</details>

Для публічного сервера перенаправте порти:

| Порт | Протокол | Призначення |
|---|---|---|
| `8088` | TCP | Вебпанель лише для довірених адміністраторів |
| `31982` | TCP | Ігровий обмін повідомленнями RabbitMQ |
| `31983` | TCP | Ігровий HTTP RabbitMQ |
| `7777-7810` | UDP | Ігровий трафік |
| `32000-32015` | UDP | Необов’язкове пряме вимірювання затримки; із закритими портами доступний ретранслятор |
| `8797` | TCP | Необов’язковий HTTPS API; [Зашифрований Доступ](../console/encrypted-api.md) |

Порти бази даних і внутрішнього адміністрування тримайте приватними. Не відкривайте вебпанель недовіреним користувачам.

## Встановлення

Використовуйте звичайний обліковий запис із `sudo`, а не вхід як `root`. Права адміністратора запитуються лише за потреби. На свіжому Linux виконайте:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | sh
```

Інсталятор завантажить останній випуск, запустить вебпанель і покаже адресу. Завершіть налаштування у браузері. Типовий шлях — `~/dune-awakening-selfhost-docker`. Для іншого диска вкажіть повний шлях:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | DUNE_INSTALL_DIR=/mnt/dune/dune-awakening-selfhost-docker sh
```

На Windows запускайте в терміналі підтримуваної Linux VM або Ubuntu WSL2, не в PowerShell, командному рядку чи внутрішній оболонці Docker Desktop. До розпакування перевіряються запис і місце; невдале завантаження не залишає частково перезаписаної інсталяції.

Alpine Linux використовує власні пакети Docker/Docker Compose та OpenRC. Якщо репозиторій community недоступний, зміна його налаштувань потребує згоди.

## Публічний Каталог Серверів

[DuneDocker.app](https://dunedocker.app/) представляє спільноти й допомагає знайти сервер. Сторінка показує стан, кількість гравців, регіон, сітчі, особисту затримку й необов’язковий Discord.

У Налаштуваннях Console можна підтвердити володіння записом, керувати профілем та запрошенням Discord і просувати сервер. Публікацію можна будь-коли перемкнути.

Прямий замір використовує UDP `32000-32015`: дозвольте його на хості, між інтернетом і DMZ та в NAT. Інакше автоматично працює ретранслятор Dune Docker, сумісність зберігається.

Локальні та суто LAN-сервери не публікуються. Типово передається лише анонімна кількість серверів без назв, адрес, гравців чи налаштувань. Цей підрахунок можна окремо вимкнути.

## Конструктор Баз

[Dune Docker Base Builder](https://blueprints.dunedocker.app/) — браузерний інструмент 3D-планування й обміну базами. Експериментуйте до витрат часу й матеріалів у грі: каталог із пошуком, розміщення, прив’язка, обертання, зіткнення та покриття території.

Змінюйте ракурс і день/ніч, гуляйте проєктом, робіть знімки, імпортуйте схеми й експортуйте готові роботи. Після входу доступні збереження, публічний/за посиланням/приватний доступ, прев’ю, перегляд і копіювання креслень спільноти. Посилання є внизу Console.
