Dune Docker Console — менеджер выделенных серверов Dune: Awakening на базе Docker для Linux, Windows/WSL2 и виртуальных машин. Он предлагает пошаговую установку и веб-панель для управления игроками, картами, резервными копиями, обновлениями и работой сервера без постоянного использования терминала.

Это неофициальный проект сообщества, не связанный с Funcom, не одобренный, не спонсируемый и не поддерживаемый этой компанией.

Проект экспериментальный. Работа серверов с самостоятельным размещением может меняться вместе с обновлениями Funcom.

## Что Вы Можете Делать

- **Устанавливать и Управлять:** Пошаговая настройка в браузере, обновления, управление службами, перезапуски по расписанию, очередь перезапусков, диагностика и восстановление.
- **Наблюдать в Реальном Времени:** Интерактивные карты, отслеживание игроков и транспорта, месторождения ресурсов, состояние сервера, производительность и журналы.
- **Настраивать Арракис:** Карты, ситчи, схемы Deep Desert, автоматическое масштабирование, память, игровые параметры и **экспериментальные Regis Tanks**.
- **Управлять Игроками:** Инструменты для игроков и гильдий, инвентарь, прогресс, базы, хранилища, транспорт, Landsraad, награды и Care Packages.
- **Управлять Экономикой:** Просмотр объявлений Exchange и автоматическая торговля с помощью встроенного Market Bot.
- **Защищать Сервер:** Копии базы данных и зашифрованные копии системы, восстановление и перенос, роли доступа, API-ключи с ограниченными правами и зашифрованный доступ к API.
- **Строить и Делиться:** Проектирование баз в 3D, импорт и обмен чертежами, публичный профиль сервера и проверка задержки.
- **Настраивать Под Себя:** Дополнения сообщества, интеграция с Discord, несколько языков Console и исправления переводов от сообщества.

Подробнее — в [Галерее Скриншотов](../screenshots.md).

## Требования

Необязательно быть специалистом по Linux. Установщик проверяет основные требования и подготавливает Docker в поддерживаемых системах Linux.

| Что Нужно | Рекомендация |
|---|---|
| Сервер | Рекомендуется свежая 64-битная Ubuntu — это самый простой вариант. Также поддерживаются другие дистрибутивы Linux, Docker Desktop на Windows/WSL2 и виртуальные машины. |
| Docker | Установщик подготавливает Docker в поддерживаемых системах Linux, если он ещё не установлен. |
| Процессор | Поддержка AVX/AVX2 |
| Память | Для начала 20 GB RAM; 30–40 GB и более для дополнительных постоянно работающих карт |
| Диск | 200 GB и более |
| Токен Funcom | Безопасно вводится при настройке в браузере |

На хостах с SELinux, например Fedora и Bazzite, конфигурация задаёт общую метку для монтирований проекта и отключает ограничение по меткам только для Console, которой нужен доступ к Docker-сокету хоста. SELinux на хосте остаётся включённым; метки и права Docker-сокета не меняются. После обновления существующей установки выполните `dune console reload`, чтобы применить эти настройки к Console. Docker должен быть установлен заранее, если его автоматический установщик не поддерживает ваш дистрибутив.

<details>
<summary>Рекомендации по Памяти и Процессору</summary>

Объём RAM определяет, сколько серверов карт смогут работать комфортно. Если сомневаетесь, начните с базовой конфигурации и добавляйте память для новых постоянно активных карт или более высокой активности игроков.

Официальный сервер Survival обычно занимает около 10–12 GB резидентной памяти даже без игроков. Один замер в простое сам по себе не доказывает утечку памяти. В `docker stats` загрузка CPU измеряется в единицах ядра: `100%` означает полную загрузку одного логического процессора.

| Конфигурация Сервера | Рекомендуемая RAM |
|---|---:|
| Базовый сервер для начала | 20 GB |
| Основной мир и дополнительные сюжетные/социальные карты | 30 GB |
| Основной мир, дополнительные карты и Deep Desert | 40 GB |
| Много постоянно активных карт или высокая активность игроков | 60 GB+ |

</details>

Для публичного сервера в интернете настройте переадресацию портов:

| Порт | Протокол | Назначение |
|---|---|---|
| `8088` | TCP | Веб-панель управления; доступ только доверенным администраторам |
| `31982` | TCP | Игровая конечная точка обмена сообщениями RabbitMQ |
| `31983` | TCP | Игровая HTTP-конечная точка RabbitMQ |
| `7777-7810` | UDP | Игровой трафик |
| `32000-32015` | UDP | Необязательные прямые проверки задержки для публичного каталога; при закрытых портах доступен ретранслятор |
| `8797` | TCP | Необязательный зашифрованный доступ к API (HTTPS); см. [Зашифрованный Доступ к API](../console/encrypted-api.md) |

Не открывайте наружу порты базы данных и внутреннего администрирования. Не предоставляйте веб-интерфейс недоверенным пользователям.

## Установка

Запускайте установщик из обычной учётной записи с доступом к `sudo`, а не из сеанса `root`. Права администратора запрашиваются только при необходимости.

Скопируйте и выполните эту команду на свежем сервере Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | sh
```

Установщик скачает последний выпуск, запустит веб-интерфейс и покажет адрес для открытия. Завершите настройку в браузере.

Путь по умолчанию — `~/dune-awakening-selfhost-docker`. Чтобы использовать другой диск Linux, явно задайте полный путь назначения:

```sh
curl -fsSL https://raw.githubusercontent.com/Red-Blink/dune-awakening-selfhost-docker/main/bootstrap.sh | DUNE_INSTALL_DIR=/mnt/dune/dune-awakening-selfhost-docker sh
```

В Windows выполняйте команду в терминале поддерживаемой виртуальной машины Linux или Ubuntu WSL2, а не в PowerShell, командной строке Windows или внутренней оболочке Docker Desktop. До распаковки установщик проверяет возможность записи и свободное место; неудачное скачивание не оставляет частично перезаписанную установку.

В Alpine Linux используются пакеты Docker и Docker Compose из дистрибутива, а Docker запускается через OpenRC. Если репозиторий community недоступен, установщик запрашивает согласие перед изменением конфигурации репозиториев.

## Публичный Каталог Серверов

[DuneDocker.app](https://dunedocker.app/) помогает владельцам публичных серверов представлять свои сообщества, а игрокам — находить подходящий сервер. Каждая запись содержит страницу с текущим состоянием, числом игроков, регионом, ситчами, индивидуальной задержкой и необязательной ссылкой на Discord.

Владельцы могут подтвердить свою запись прямо в Настройках Console, подтвердить владение, управлять публичным профилем и приглашением Discord, а также продвигать сервер через каталог. Публикацию можно включить или выключить в любое время.

Для наиболее быстрой прямой проверки задержки используется UDP `32000-32015`. Разрешите этот диапазон в брандмауэре хоста и на любом брандмауэре между интернетом и DMZ либо в перенаправлении NAT. Серверы с закрытым диапазоном остаются совместимыми и автоматически используют ретранслятор Dune Docker.

Локальные серверы и серверы только для LAN никогда не публикуются. По умолчанию установки участвуют лишь в анонимном подсчёте серверов: без названий, адресов, игроков или настроек. Эту функцию можно отдельно отключить в Настройках.

## Конструктор Баз

[Dune Docker Base Builder](https://blueprints.dunedocker.app/) — браузерный инструмент для проектирования баз Dune: Awakening в 3D и обмена проектами. Проверяйте планировки до затрат времени и материалов в игре, используя каталог конструкций и объектов с поиском, размещением, привязкой, вращением, проверкой столкновений и покрытия территории.

Просматривайте проект с разных сторон, переключайте день и ночь, проходите по готовой планировке и делайте скриншоты. Существующие планировки можно импортировать для планирования, а готовые — экспортировать для дальнейшего использования.

Вошедшие в систему участники могут сохранять проекты, выбирать публичный, доступный по ссылке или приватный режим, публиковать превью, изучать проекты сообщества и копировать опубликованный чертёж как основу. Ссылка на конструктор есть и в нижней части Console.
