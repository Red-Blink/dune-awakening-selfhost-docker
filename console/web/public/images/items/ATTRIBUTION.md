## Game Icons

The 666 game-icon additions in PR #278 were extracted by drkshrk from
Dune: Awakening client textures, including item RenderedIcon textures, building-set
piece icons, and customization icons. Dune: Awakening artwork belongs to its
respective rights holders, including Funcom. Some icons were padded with transparent
pixels to fit thumbnail frames. Variant matching used the community wiki's
[Cosmetics catalog](https://awakening.wiki/Cosmetics).
See the repository [NOTICE](../../../../../NOTICE) for the project disclaimer.

## Generated Swatch Tiles

The following 112 palette-preview images were generated by drkshrk as four-color
tiles from palette information documented by Dune: Awakening Community Wiki
contributors. They are previews generated for this Console, not extracted game
textures.

- Source and contributor history: [Cosmetics — Swatches](https://awakening.wiki/index.php?title=Cosmetics&oldid=124572#Swatches)
  and its linked swatch pages.
- Attribution: Dune: Awakening Community Wiki contributors; tile generation by drkshrk.
- License for these palette-derived tiles: [Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-nc-sa/4.0/).
- Changes: palette values rendered as four rounded color blocks on a transparent
  square, named for the corresponding catalog template.
